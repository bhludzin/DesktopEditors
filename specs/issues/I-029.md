## What differs

Found by the 3963-slide deck's review (run i024-c, sdkjs f53e0a4a15). A knife emoji (U+1F52A) at the end of a 14-pt line is drawn by Euro-Office as the black outline glyph of Segoe UI Emoji. PowerPoint writes it as a 96x81 colour bitmap (brown handle, grey blade). The position and size match; the colour and shape do not. Slides (11): 734-736, 751-758.

## What PowerPoint does

Draws a colour emoji in its colours. Its PDF holds each one as an image, not text: the knife at 14 pt is a 96 x 81 RGB image at about 200 dpi (34.6 x 29.5 pt, glyph plus transparent margin, Flate with an SMask) placed where the glyph goes in the line.

## What Euro-Office does

Before the fix: drew the glyph as Segoe UI Emoji's single outline, filled with the text colour (black). Now, in slides, a glyph whose font has COLR (version 0 records) and CPAL tables is drawn as its COLR layers, bottom to top, each layer glyph filled with its colour from palette 0 (palette index 0xFFFF takes the text colour; palette alpha is multiplied by the text alpha), and the text colour is restored afterwards. The code points go with the first layer only, so the emoji is extracted once. The layers are vector glyphs, so the PDF keeps the emoji as text and it stays sharp at any zoom, where PowerPoint's is a 200-dpi image. At 4000 px the knife's outline, brown handle with its rivets and grey blade match PowerPoint's to about a pixel of its image.

## Suspected cause

Cause found: nothing in sdkjs or core reads COLR or CPAL. The font engine and the PDF writer draw every glyph as one outline in the current brush colour.

## Where to look

sdkjs common/libfont/grapheme.js: DrawGrapheme uses GetColorGlyphDrawer / CColorGlyphDrawer when the grapheme's font has a colour table (ReadColorGlyphTable parses COLR v0 and CPAL palette 0 from the font bytes, AscFonts.getFontStream; cached per font file and face). Presentation editor only, and only on AscCommon.CDocumentRenderer (PDF, with a solid brush) and AscCommon.CGraphics (canvas), whose brush colour can be read back and restored; other contexts draw the outline as before.

## Fix idea

Done (see euro_office). Not done: drawing an image as PowerPoint does; COLR version 1 paint graphs (gradients, as in Windows 11's Segoe UI Emoji, whose version 0 records are used instead); palettes other than 0; bitmap colour fonts (sbix, CBDT).

## Open questions
